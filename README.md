# Hand Portal AR 🖐️

A small experimental computer vision project that transforms a webcam feed into interactive, hand-controlled portal effects.

Built with **Python, OpenCV, and MediaPipe**, the project uses hand tracking to detect hand landmarks and create visual effects that respond to hand movements.

###  Features
- Real-time hand tracking
- Perspective-transformed portal effect
- Four visual modes: Night Vision, Thermal, Cyberpunk, and Kaleidoscope
- Keyboard controls for switching effects

### Tech Stack
- Python
- OpenCV
- MediaPipe
- NumPy

This is a personal experimental project built for fun, exploring computer vision, real-time image processing, and AI-powered hand tracking.
